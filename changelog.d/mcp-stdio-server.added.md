- `huntsman-recon mcp` runs the binary as a Model Context Protocol server over stdio, so Claude Desktop, Claude Code, Cursor and other LLM applications can call Huntsman as a tool. Its `lookup`, `people_discover` and `research` tools run the same adapters `serve` installs for `/api/lookup`, `/api/people/discover` and `/api/research`, with the same keys and egress. A lookup answers with a size-bounded summary by default (live: `8.8.8.8` 6.9 MB full, 124 KB summary; every source outcome and per-kind count kept, every cut counted) and the whole report with `detail: "full"`. It negotiates protocol revisions 2025-11-25, 2025-06-18, 2025-03-26 and 2024-11-05, answers batches, refuses lines over 1 MiB without holding them, and reports bad arguments as tool errors the model can correct. The public-search names (`news`, `notices`, `web`, `dossier`) now live once, in `public_osint::Source::NAMED`.
