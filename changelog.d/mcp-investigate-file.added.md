- The MCP `investigate_file` tool: one local file, by its path on the machine the server runs
  on, read as `investigate --file` reads it (a text file for the selectors in it and its embedded
  metadata; a photo, a PDF or a document for its embedded metadata, GPS position and the
  addresses, links and names written into its fields) and reported as `investigate` reports a
  text. Offline, no key; a symlink is refused and the file is never modified. An LLM client of
  the server can now read a file on the phone without pasting it.
