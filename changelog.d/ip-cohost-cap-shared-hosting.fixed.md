- An `ip` lookup of an address that more than 100 names resolve to (Spiderfoot's `maxcohost` default) now calls it shared hosting: the address and each such name are tagged `shared-hosting`, the address's evidence says how many names resolved to it, and each name's confidence falls to 0.30, below the floor a recursive scan follows, so a crawl no longer pivots through a hosting provider or an anycast service. Nothing is dropped: every name stays in the report with the evidence that found it, and a name a stronger source also links keeps that higher confidence when the entities merge. Live, `ip 8.8.8.8` had emitted 1,680 co-hosted names at confidence 0.60, every one a pivot candidate.
