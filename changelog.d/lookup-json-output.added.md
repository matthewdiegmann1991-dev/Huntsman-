- Every typed lookup command (`people`, `email`, `exposure`, `username`, `phone`, `domain`, `ip`, `netblock`, `asn`, `network`, `crypto`, `geocode`) takes `--json`: one JSON object on one line, the shape `GET /api/lookup` and the MCP `lookup` tool return, for agents and scripts that run the binary and read its output. With `--save` the ledger receipt is a `saved` object inside it, so standard output holds that object alone; argument errors keep their stderr message and exit status. The flag lives in the one function every typed lookup finishes through, and each command's `--help` documents it.
