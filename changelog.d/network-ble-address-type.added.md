- `network BSSID` now also reads the address as a Bluetooth LE address, offline: public (an IEEE-registered prefix), static random, resolvable private or non-resolvable private, from its top two bits, with what each means for recognising the device later (`ble_address_kind` on the offline evidence, and the summary). A random Bluetooth address sets or clears the Wi-Fi U/L bit by chance, so half of all rotating phone addresses had read as "universally administered, unregistered" and got no offline evidence at all; now every well-formed address gets its reading, and a resolvable private one is told apart before any WiGLE query is spent on it.
