- The container image compiles its dependencies in a layer keyed on the manifests alone, before the sources are copied and before the per-commit build arguments are declared, so a rebuild for a new commit (every deploy on Railway or any Docker host) reuses them. Measured on 4 cores: a rebuild after a one-line source change fell from 102 s to 91 s; a cold build is unchanged (102 s to 106 s). The crate's own stub artifacts are removed before the real build, and the rebuilt image was checked to embed the new commit and run the real binary. A test holds the layer order.
