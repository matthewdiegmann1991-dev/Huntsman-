- `investigate --json` and `research --json`, for agents that run the binary and read what it prints. `investigate --json` (the flag given anywhere, so it is never read as part of the text) prints the one object `POST /api/investigate` and the MCP `investigate` tool return; `research --json` prints the typed scan route's `/api/lookup` object, the adaptive web route's `/api/research` object (route and report), or, with `--plan`, the chosen route as an object. Before, `investigate` scanned the literal text `--json` and `research --json` was a usage error.
