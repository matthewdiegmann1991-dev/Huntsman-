- `install.sh` and `install-termux.sh` take `HUNTSMAN_REPO=OWNER/NAME` to install from another copy of the repository, such as a fork: the source build, prebuilt release and helper scripts all come from it, and the install record names it. The default is unchanged. Every URL the installers build came from a hard-coded owner, so a copy of the repository installed the original's code without saying so. The value is checked against GitHub's owner and name syntax before anything is fetched, because it is spliced into URLs.
