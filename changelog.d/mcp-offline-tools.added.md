- The MCP server gains two offline tools, `investigate` (the selectors in a text, as `POST /api/investigate` extracts them) and `analyze` (the multi-hop analysis of up to 16 seeds, as `GET /api/analyze` runs it), both running the adapters `serve` installs and making no request. They are annotated `openWorldHint: false` and `idempotentHint: true`, so a model can call them freely; the three live tools keep `openWorldHint: true`. An agent's loop is now complete inside one server: extract selectors from pasted material, look up the ones worth following, then analyse the set for the links between them.
