- The `install-termux.sh` a release publishes now installs from the repository that published it: the release job stamps `RECON_REPO_DEFAULT` with the publishing repository beside the tag it already stamped, and proves both stamps took before it publishes. A release of any other copy of this repository (a fork, or a new home) had told its users to run an installer that fetched the original repository's release of the same tag, which that repository had never published. The checkout's unstamped copy keeps its named default, and `HUNTSMAN_REPO=OWNER/NAME` still overrides either.
